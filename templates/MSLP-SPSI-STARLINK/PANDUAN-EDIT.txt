    Kotak login sengaja dibuat tembus, supaya wallpaper di img/bg.jpg

      Tulisan susah dibaca?           naikkan ke .3 atau .45

      Naikkan angkanya kalau wallpaper terlalu ramai di balik tulisan.

    TIMBANG DULU: video diunduh pelanggan SEBELUM mereka punya internet.
    Video 3 MB bisa membuat halaman login baru muncul 20-30 detik.
    Pakai hanya untuk hotspot indoor bersinyal kuat.

    Menyalakan:
      1. Taruh  bg.mp4  di folder  img/
      2. Cari  var PAKAI_VIDEO = false;  ubah jadi  true

    Ukuran video: 720x1280, 8-12 detik, MP4/H.264, TANPA SUARA,
    di bawah 1 MB. Contoh perintah ffmpeg:

      ffmpeg -i asli.mp4 -t 10 -an -vf "scale=720:1280,fps=24" \
             -c:v libx264 -profile:v baseline -crf 30 -movflags +faststart img/bg.mp4

    Kalau video gagal / diblokir HP, halaman otomatis kembali ke bg.jpg.
    Jadi bg.jpg WAJIB tetap ada walau memakai video.

  MEMATIKAN GERAKAN
    Cari  @keyframes bgGerak  lalu pada baris  .bg{...animation:bgGerak 46s...}
    ganti isinya jadi  animation:none
    Percikan: cari  .spark{position:fixed  tambahkan  display:none;

===============================================================================
  10. UPLOAD KE MIKROTIK
===============================================================================

  CARA DIANJURKAN - folder terpisah
    1. Winbox > Files > buat folder baru, misalnya  spsistarlink
    2. Blok semua file di folder ini (JANGAN preview.html), drag ke situ
       (sertakan folder img/ dan font/)
    3. IP > Hotspot > Server Profiles > profile Anda
    4. HTML Directory diisi:  spsistarlink
    5. Apply > OK

  SETELAN PROFILE
    IP > Hotspot > Server Profiles > tab Login
      Centang HTTP CHAP dan HTTP PAP. md5.js wajib ikut terupload.

  AGAR TOMBOL WHATSAPP BISA DIKLIK SEBELUM LOGIN
    Tanpa ini, kartu paket dan tombol WhatsApp tidak akan terbuka.

      /ip hotspot walled-garden
      add dst-host=wa.me comment="WA MIKROSETTING"
      add dst-host=*.wa.me comment="WA MIKROSETTING"
      add dst-host=*.whatsapp.com comment="WA MIKROSETTING"
      add dst-host=*.whatsapp.net comment="WA MIKROSETTING"
      add dst-host=*.cdn.whatsapp.net comment="WA MIKROSETTING"

      /ip hotspot walled-garden ip
      add dst-host=*.whatsapp.com action=accept comment="WA MIKROSETTING"
      add dst-host=*.whatsapp.net action=accept comment="WA MIKROSETTING"

  MENGETES
    Sambungkan HP ke wifi hotspot. Kalau halaman tidak muncul sendiri,
    buka browser lalu ketik IP hotspot Anda, contoh http://192.168.88.1/login

===============================================================================
  11. LISENSI   (khusus MIKROSETTING, jangan dijelaskan ke pembeli)
===============================================================================

  Halaman hanya tampil kalau kunci lisensinya cocok dengan router tempat
  dia dipasang. Kalau tidak cocok, muncul layar "LISENSI TIDAK AKTIF"
  berisi ID ROUTER dan tombol minta lisensi.

  Kunci berlaku SELAMANYA, tanpa masa berlaku. Yang dijaga satu hal:
  satu kunci untuk satu router. Begitu foldernya dipindah atau dijual
  ke MikroTik lain, halamannya terkunci.

  SATU KUNCI UNTUK SEMUA TEMA
    Semua tema (Naruto, MOBA, PUBG, FF, UMUM, dan folder ini)
    memakai LIS_SALT yang sama,
    jadi satu kunci berlaku untuk semuanya di router yang sama.
    Kalau ingin tiap tema dijual terpisah, beri LIS_SALT berbeda per tema
    dan simpan generator terpisah untuk masing-masing.

  SAMPAI DI MANA LISENSI INI MELINDUNGI
    BISA dicegah : folder disalin lalu dipakai di router lain
    BISA dicegah : pembeli menjual ulang template ke orang lain
    TIDAK bisa   : orang yang paham HTML membuka file lalu menghapus
                   blok pemeriksa lisensi
    Ini pagar, bukan brankas.

  JANGAN SAMPAI TERTUKAR
    var LIS_KEY   = KUNCI dari generator, bentuknya 4-4-4
    var LIS_SALT  = RESEP RAHASIA, bukan nama router dan bukan kunci.
                    Harus sama persis dengan generator-lisensi.html
    Kesalahan paling sering: kedua baris diisi nama router. Akibatnya
    halaman terkunci selamanya.

  var LIS_MODE
    "kunci" = blokir halaman kalau tidak cocok
    "ingat" = tetap boleh login (darurat kalau pembeli terkunci)

  ALUR PENJUALAN
    1. Kirim folder dengan LIS_KEY dikosongkan.
    2. Pembeli upload, buka halaman login, muncul ID ROUTER.
    3. Pembeli kirim ID ROUTER (tombol WhatsApp sudah otomatis memuatnya).
    4. Buka generator-lisensi.html, tempel ID, tekan BUAT KUNCI LISENSI.
    5. Kirim satu baris hasilnya, pembeli timpa di login.html, upload ulang.

  SALT saat ini: GANTI-DENGAN-SALT-RAHASIA-ANDA
    GANTI dengan kalimat rahasia Anda sendiri sebelum berjualan, di
    login.html SEMUA TEMA dan di generator-lisensi.html sekaligus.
    Sesudah ada kunci terbit, jangan diubah lagi.

  ID ROUTER dari mana
    Dari $(identity), yaitu System > Identity di Winbox. Kalau versi
    RouterOS tidak mengenalnya, otomatis memakai $(server-address).
    Kalau pembeli mengganti Identity, lisensinya berhenti cocok dan
    perlu kunci baru. Jangan pakai tanda kutip " pada Identity.

  MENGUJI DI KOMPUTER
    Buka preview.html. Karena tidak ada router yang menerjemahkan
    $(identity), halaman masuk MODE UJI dan tidak pernah dikunci.

  12. JANGAN DIUBAH

    - fungsi fitOneScreen()
    - satuan svh pada min-height:100svh di blok .app

  Jangan mengubah nama file login.html dan md5.js, kata di dalam class="",
  id="card" id="tabV" id="tabM" id="fUser" id="fPass" id="inUser" id="inPass"
  id="lisBlok" id="lisId" id="lisWa" id="bgvid", serta name="username"

===============================================================================
  13. TIGA TINGKAT UKURAN LAYAR
===============================================================================

  HP     : di bawah 600px  -> setelan dasar, ukuran ikut TINGGI layar
           (+ @media max-width:340px dan max-height:460px)
  Tablet : 600px - 1023px  -> @media (min-width:600px), lebar isi maks 760px
  Laptop : 1024px ke atas  -> @media (min-width:1024px), lebar isi maks 900px

  Semua tingkat memakai clamp(kecil, ...vh, besar) supaya tetap muat
  satu layar. Penjaga fitOneScreen() berlaku di semua ukuran: kalau
  isinya masih kelebihan, halaman dikecilkan sendiri maksimal 22%.

  MENGETES: buka preview.html di Chrome, F12, Ctrl+Shift+M, ketik lebar
  360 (HP), 768 (tablet), 1280 (laptop).
